# Shopeease Sentiment Analysis NLP Application

End-to-end NLP application for analyzing customer sentiment from e-commerce reviews. The project covers text preprocessing, sentiment modeling, prediction workflows, and a Streamlit interface for business users.

## Objective

This project is organized as a portfolio case study to show the full analysis workflow: understanding the business problem, preparing the data, exploring patterns, building the final output, and communicating insights clearly.

## Business Questions

- What sentiment patterns appear in customer feedback?
- How can review text be transformed into model-ready features?
- Can the application classify new customer reviews reliably?

## Tools Used

- Python
- pandas
- scikit-learn
- NLP preprocessing
- Streamlit
- Modular ML pipeline
